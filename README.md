A Trello-inspired web application for managing tasks and lists, developed with HTML, CSS and Vanilla JavaScript.

# 🇩🇪 Deutsch

## 📌 Projektbeschreibung

Dieses Projekt ist eine an Trello angelehnte Webanwendung zur Verwaltung und Organisation von Aufgaben.

Es wurde im Rahmen meiner Ausbildung zum Applikationsentwickler EFZ entwickelt. Im Mittelpunkt standen die Umsetzung einer interaktiven Benutzeroberfläche, die Kommunikation mit einer REST-API und die strukturierte Entwicklung mit JavaScript.

## 🚀 Funktionen

- **Aufgabenverwaltung:** Aufgaben erstellen, anzeigen, bearbeiten und löschen (CRUD).
- **Listenverwaltung:** Aufgaben in verschiedenen Listen organisieren.
- **Suchfunktion:** Aufgaben gezielt suchen.
- **Pagination:** Datensätze auf mehrere Seiten verteilen.
- **Bearbeitungsfenster:** Aufgaben über interaktive Modals bearbeiten.
- **Ladeanimationen:** Visuelles Feedback während API-Anfragen.
- **API-Kommunikation:** Daten mit der Fetch API vom Backend abrufen und übermitteln.
- **Asynchrone Verarbeitung:** API-Anfragen mit `async/await` verarbeiten.

## 🛠️ Technologien

| Technologie | Verwendung |
|---|---|
| HTML5 | Struktur der Benutzeroberfläche |
| CSS3 | Layout und Gestaltung |
| JavaScript (ES6+) | Programmlogik und Interaktivität |
| Fetch API | Kommunikation mit dem Backend |
| REST API | Datenaustausch und CRUD |
| Git & GitHub | Versionsverwaltung |

## 🏗️ Architektur

Das Projekt orientiert sich am MVC-Prinzip (Model-View-Controller).

- **Model:** Verwaltet die Anwendungsdaten und die Kommunikation mit der API.
- **View:** Stellt Daten dar und aktualisiert die Benutzeroberfläche.
- **Controller:** Verarbeitet Benutzeraktionen und verbindet Model und View.

Durch diese Aufteilung bleibt der Code übersichtlich und leichter wartbar.

## ⚙️ Installation

### Voraussetzungen


# 🇬🇧 English

## 📌 Project Description

This project is a Trello-inspired web application designed to manage and organize tasks.

It was developed as part of my education as a software application developer (Swiss EFZ apprenticeship). The main focus was building an interactive user interface, communicating with a REST API, and writing structured JavaScript code.

## 🚀 Features

- **Task Management:** Create, display, edit, and delete tasks (CRUD).
- **List Management:** Organize tasks into different lists.
- **Search:** Search for specific tasks.
- **Pagination:** Split data into multiple pages.
- **Edit Modals:** Modify tasks through interactive popup windows.
- **Loading Indicators:** Provide visual feedback during API requests.
- **API Integration:** Retrieve and send data using the Fetch API.
- **Asynchronous Operations:** Handle API communication using `async/await`.

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | User interface structure |
| CSS3 | Styling and layout |
| JavaScript (ES6+) | Application logic and interactivity |
| Fetch API | Backend communication |
| REST API | Data exchange and CRUD operations |
| Git & GitHub | Version control |

## 🏗️ Architecture

The project follows the MVC (Model-View-Controller) design pattern.

- **Model:** Manages application data and API communication.
- **View:** Displays data and updates the user interface.
- **Controller:** Handles user interactions and connects the model and view.

This separation helps keep the code organized, maintainable, and easier to extend.

## ⚙️ Getting Started

### Prerequisites

- Modern web browser

- Running backend API for server-dependent features

### Clone the Repository

```bash
git clone https://github.com/hackychristki/Trello-Frontend-Projekt-2-.git
cd Trello-Frontend-Projekt-2-
```

Start the frontend using a local development server, such as the Live Server extension in Visual Studio Code.

Ensure that the required backend API is running and accessible.
